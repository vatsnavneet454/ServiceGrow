# ServiceGrow Website Starter

Responsive homepage built with HTML, CSS and JavaScript.

## Run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Files
- `index.html` — homepage and sections
- `css/style.css` — design and responsive layouts
- `js/main.js` — mobile menu and demo form interaction

## Before going live
- Replace `hello@servicegrow.example` with a real business email.
- Add final Privacy Policy and Terms & Conditions.
- Connect the contact form to a secure backend or trusted form provider.
- Add real calendar booking integration, analytics and final SEO details.
- Test on mobile and desktop.

IMPORTANT: The contact form is frontend-only. It does not send or store submissions until connected to a backend.
